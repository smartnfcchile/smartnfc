# SmartNFC UV 2.0

La ruta de demostración es `/demo/uv-2` en entornos aislados. Usa el mismo renderizador que las campañas y datos de ejemplo. La imagen acuícola es ilustrativa, generada para la demostración.

## Manual de Agustín

1. En el editor de una campaña, abre **Identidad y sedes → Estilo → Editorial** si quieres la cabecera compacta y el hero azul oscuro.
2. Agrega una **Tarjeta informativa** o **Alerta preventiva**. Escribe un título, una descripción y elige un icono.
3. Usa **Indicador destacado** para destacar un aviso. Puedes añadir un botón con un destino HTTPS. La demo enlaza al pronóstico oficial sin capturar ubicación ni mostrar una medición actual.
4. En **Escala de riesgo**, personaliza el rango, la etiqueta y el color de cada tramo. Usa la nota para explicar qué representa la escala.
5. Crea un **Grupo de tarjetas** para mostrar medidas en una cuadrícula. Puedes añadir hasta ocho tarjetas.
6. Guarda el borrador y revisa la vista móvil. Selecciona una sede si necesitas una variante y protege los bloques corporativos que deban permanecer iguales. Aprobar, publicar y activar son pasos separados.

Los bloques se almacenan en el contenido versionado existente. Una fuente futura de medición debería alimentar el indicador mediante un contrato separado del contenido guardado, con origen, fecha y estado de disponibilidad. La demo actual es informativa.
